GitHubSync

Überträgt Dateien zu GitHub und lädt Projektdateien oder Release-Dateien nach Bestätigung herunter.

Release · 1.5.3 Windows 10/11 · x64
Herunterladen für WindowsQuellcode C# · WPFAnleitung ↗

Vor dem StartWindows PowerShell 5.1 und .NET Framework 4.6.2+ mit WPF; Git/GCM sind enthalten. EXE ohne digitale Signatur. Uploads benötigen Internet und Schreibzugriff.

Was drin steckt

Installation, Funktionen, Datenschutz, Prüfung.

Installation

Archiv prüfen, entpacken, starten.

PS> Get-FileHash .\GitHubSync-1.5.3-win-x64.zip -Algorithm SHA256
PS> Get-Content .\GitHubSync-1.5.3-win-x64.zip.sha256
Beide Werte müssen übereinstimmen.
PS> Expand-Archive .\GitHubSync-1.5.3-win-x64.zip -DestinationPath .\GitHubSync
PS> .\GitHubSync\GitHubSync-1.5.3-Portable\GitHubSync.exe

Verbindung

Spricht nur mit GitHub (API und Dateidownloads über HTTPS). Die Anmeldung läuft im Browser; die App speichert keine Passwörter oder Tokens und fügt keine Telemetrie hinzu.

Geprüft

  • Testskripte auf Windows per GitHub Actions (mit simuliertem GitHub, ohne echtes Konto)
  • Build des Launchers im CI
  • Prüfung der Veröffentlichungsdateien
  • SHA-256-Prüfsumme für das Portable-ZIP
  • MIT-Lizenz mit Hinweisen zu Drittanbietern
  • Oberfläche und Anleitung in Deutsch, Russisch und Englisch

So funktioniert es

  1. Repository wählen
  2. Dateien prüfen
  3. In Code oder Releases hochladen

Erste Schritte

SHA-256 prüfen, das vollständige Portable-Paket entpacken und GitHubSync.exe öffnen. Senden/Herunterladen, Projekt, Ziel und Dateien wählen; bestätigen.
