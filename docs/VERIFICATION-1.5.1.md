# Verification of GitHubSync 1.5.1

This is a local release candidate, not a publicly distributed release. Earlier sections record offline preparation; the live acceptance section below records the subsequent owner-approved tests.

The regression suite `tests/Test-TransferFixes.ps1` verifies all sixteen Windows Cloud tag variants, native metadata from the actual source ancestry under OneDrive, ordinary/Cloud Code source validation, and an actual NTFS junction escape rejected by both upload and download. It re-runs the download transport fixtures under OneDrive with artificial data, covering Code and release downloads, Unicode, binary bytes, replacements/backups, partial resume, checksum errors, long paths and credential-free metadata.

`tests/WriteTransportReview.cs` checks exact streamed JSON and Content-Length for empty, padded and 61 MiB artificial binary payloads, bounded chunks, byte-progress snapshots without credentials, publication JSON, HTTP rejection categories, sanitized request IDs, configured deadlines and no mutation retries. PS5 wrapper checks cover configured upload timeout and all three languages.

The original Code failure's server status was discarded by version 1.5.0 and is not recoverable from its screenshot. Windows PowerShell 5.1 serialization of an 84 MiB string was checked successfully, ruling out the suspected JSON-length failure. The hard-coded 120-second deadline and unnecessary complete request buffers have been replaced, and precise diagnostics added. No claim is made that this proves the user's account can write the selected branch.

Completed on Windows in Windows PowerShell 5.1: all 13 backend/package suites, 86 write-transport assertions, 78 baseline download assertions plus the same download suite under real Cloud ancestry, and 485 WPF assertions with Deutsch/Русский/English renders at 100–200%. The 6000-file UI scan remained responsive; switching away took 19 ms in this run. Native Cloud metadata and junction checks passed. Source syntax/BOM, documentation links and credential-pattern audits passed. The WPF download/progress renders were also visually inspected.

Real-user uploads, live GitHub writes, publication, branch-protection bypass and credential-store changes are outside these tests. Physical Windows DPI changes and other PCs are unverified. [Architecture](ARCHITECTURE.md) describes the baseline; the release checksum refers to the new clean archive, not a used installation.
