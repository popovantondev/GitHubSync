GitHubSync

Upload files to GitHub and download project files or release attachments after your confirmation.

Release · 1.5.3
Download for WindowsUser guide ↗

Before you startWindows PowerShell 5.1 and .NET Framework 4.6.2+ with WPF; Git/GCM are bundled. EXE is unsigned. Uploads require internet and repository write access.

How it works

  1. Select a repository
  2. Review files
  3. Upload to Code or Releases

First steps

Verify SHA-256, extract the complete portable package and open GitHubSync.exe. Choose Send/Download, repository, destination and files, then confirm.
