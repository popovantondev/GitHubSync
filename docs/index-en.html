GitHubSync

Upload files to GitHub and download project files or release attachments after your confirmation.

Release · 1.5.3 Windows 10/11 · x64
Download for WindowsSource code C# · WPFUser guide ↗

Before you startWindows PowerShell 5.1 and .NET Framework 4.6.2+ with WPF; Git/GCM are bundled. EXE is unsigned. Uploads require internet and repository write access.

What's inside

Installation, features, privacy, checks.

Installation

Verify, extract, start.

PS> Get-FileHash .\GitHubSync-1.5.3-win-x64.zip -Algorithm SHA256
PS> Get-Content .\GitHubSync-1.5.3-win-x64.zip.sha256
Both values must match.
PS> Expand-Archive .\GitHubSync-1.5.3-win-x64.zip -DestinationPath .\GitHubSync
PS> .\GitHubSync\GitHubSync-1.5.3-Portable\GitHubSync.exe

Connection

Talks only to GitHub (API and file downloads over HTTPS). Sign-in happens in the browser; the app stores no passwords or tokens and adds no telemetry.

GitHub APIHTTPSBrowser sign-in

First steps

Verify SHA-256, extract the complete portable package and open GitHubSync.exe. Choose Send/Download, repository, destination and files, then confirm.
