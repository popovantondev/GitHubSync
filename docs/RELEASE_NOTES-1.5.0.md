# GitHubSync 1.5.0

GitHubUploader becomes GitHubSync: the same WPF app, with approved transfers in both directions.

- Send or Download in one window; Code files and release attachments have separate sources and local destinations.
- Read-only catalogs support readable repositories, optional public access, default branches and published releases.
- Streamed downloads, pause/resume, partial-file persistence, available checksum verification and replacement backups.
- Conditional GitHub update checks every 15 minutes, never automatic upload/download or publication.
- Closing hides to the tray; approved work continues. Explicit Exit pauses downloads and warns before stopping uploads.
- Two-arrow icon with shared tray/window animation frames and static executable icon.
- Backward-compatible upload settings, three-language offline HTML instructions, clean portable/source packaging.

No destructive mirror, automatic executable launch, Git LFS/submodules/history download, protected-branch bypass or byte-resume of unfinished uploads. Physical DPI switching, another PC and real private-account acceptance must be reported separately from synthetic tests. This is a local candidate, not a published GitHub release.
