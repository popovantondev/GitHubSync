GitHubSync

Überträgt Dateien zu GitHub und lädt Projektdateien oder Release-Dateien nach Bestätigung herunter.

Release · 1.5.3
Herunterladen für WindowsAnleitung ↗

Vor dem StartWindows PowerShell 5.1 und .NET Framework 4.6.2+ mit WPF; Git/GCM sind enthalten. EXE ohne digitale Signatur. Uploads benötigen Internet und Schreibzugriff.

So funktioniert es

  1. Repository wählen
  2. Dateien prüfen
  3. In Code oder Releases hochladen

Erste Schritte

SHA-256 prüfen, das vollständige Portable-Paket entpacken und GitHubSync.exe öffnen. Senden/Herunterladen, Projekt, Ziel und Dateien wählen; bestätigen.
