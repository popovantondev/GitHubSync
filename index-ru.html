GitHubSync

Отправляет файлы в GitHub и скачивает исходники или файлы выпусков после подтверждения пользователя.

Выпуск · 1.5.3 Windows 10/11 · x64
Скачать для WindowsИсходный код C# · WPFРуководство ↗

Перед запускомWindows PowerShell 5.1 и .NET Framework 4.6.2+ с WPF; Git/GCM входят в portable. EXE без цифровой подписи. Для отправки нужны интернет и права записи в проект.

Что внутри

Установка, функции, данные, проверка.

Установка

Проверить архив, распаковать, запустить.

PS> Get-FileHash .\GitHubSync-1.5.3-win-x64.zip -Algorithm SHA256
PS> Get-Content .\GitHubSync-1.5.3-win-x64.zip.sha256
Оба значения должны совпадать.
PS> Expand-Archive .\GitHubSync-1.5.3-win-x64.zip -DestinationPath .\GitHubSync
PS> .\GitHubSync\GitHubSync-1.5.3-Portable\GitHubSync.exe

Подключение

Работает только с GitHub (API и загрузка файлов по HTTPS). Вход выполняется в браузере через входящий в пакет Git Credential Manager; само приложение не хранит пароли и токены (менеджер держит вход в защищённом хранилище Windows) и не добавляет телеметрию.

Проверено

  • Тестовые сценарии на Windows через GitHub Actions (имитация GitHub, без настоящего аккаунта)
  • Сборка лаунчера в CI
  • Проверка публикуемых файлов
  • Контрольная сумма SHA-256 для переносного ZIP
  • Лицензия MIT и сведения о сторонних компонентах
  • Интерфейс и руководство на немецком, русском и английском

Как это работает

  1. Выбрать репозиторий
  2. Проверить файлы
  3. Загрузить в Code или Releases

Первые шаги

Проверьте SHA-256, распакуйте весь portable-пакет и откройте GitHubSync.exe. Выберите отправку или скачивание, проект, назначение и файлы; подтвердите действие.
